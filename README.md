# Vibe Forge

You are building a professional-level Vibe Coder — a premium AI-powered coding platform like Lovable, but with a more polished, powerful, and production-ready experience.

Goal:
Create a full-stack product that lets users describe ideas in natural language and instantly turn them into working apps, pages, components, and workflows. This is not a demo. It should feel like a real SaaS product that developers, founders, and creators can use.

What “Vibe Coder” should do:

Let users type a simple idea and generate a complete working app

Support editing, previewing, and refining the generated app

Make code generation feel fast, smart, and highly reliable

Give users the ability to iterate naturally through prompts

Produce modern, clean, maintainable code

Make the experience feel like an elite AI coding assistant platform

Product quality bar:

Build something that feels like Lovable-level or better

The UI must be sleek, modern, and professional

Make it feel premium, polished, and trustworthy

Use strong spacing, clean typography, and responsive layouts

Include proper loading, empty, error, and success states

Ensure every interaction feels smooth and deliberate

Core features:

Natural language app generation

Live preview of the generated app

Editable code or component structure

Prompt-to-update workflow

Project history or versioning

Export or save functionality

Responsive design for desktop and mobile

Clean onboarding for first-time users

Smart AI suggestions for improving the build

Engineering requirements:

Write clean, modular, scalable code

Use reusable components

Keep the architecture production-ready

Avoid placeholder-only logic

Ensure the app is functional end to end

Structure the project like a real startup product

Handle edge cases gracefully

Make the codebase easy to extend

Design requirements:

Minimal but powerful aesthetic

Modern SaaS style

Clear hierarchy and obvious primary actions

Subtle motion and transitions

No clutter, no fake dashboard noise

Every element must have a purpose

AI behavior:

Act like a senior product engineer, UI/UX designer, and startup builder

Make smart decisions when details are missing

Choose the most polished and user-friendly implementation

Prioritize usability, speed, and clarity

Think like a real product team building a launch-ready Vibe Coder

Output expectation:

Build the full working product

Make it feel complete and launch-ready

Include all core flows needed for a real user

Summarize what was created at the end

Keep the result premium, cohesive, and professional

Extra instruction:
This is a Vibe Coder product, so the experience should feel magical, fast, and creator-friendly, while still being technically solid and production-grade.
